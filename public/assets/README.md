# Mídia oficial pendente

Esta árvore está pronta para receber arquivos autorizados da LavaMed:

```text
brand/
  lavamed-logo.png
before-after/
  trabalho-001/
    antes.webp
    depois.webp
gallery/
hero/
  lavamed-conceito-cinematografico.png
```

Regras de publicação:

- Não usar banco de imagens como portfólio.
- Pares de antes/depois devem mostrar o mesmo veículo.
- Confirmar autorização para placas, pessoas e depoimentos identificáveis.
- Substituir o aviso de logo pendente apenas quando o arquivo oficial for entregue.
